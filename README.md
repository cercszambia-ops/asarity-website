# Asarity Safety Wear Solutions Limited — Website

Responsive static website using Asarity's orange, black and white identity. The website photographs are the original images supplied for this project and have been copied without retouching, recolouring, enhancement or AI modification. Website display sizing/cropping is controlled by CSS.

## Files
- `index.html` — site content
- `styles.css` — responsive layout and styling
- `script.js` — mobile navigation and email enquiry form
- `assets/asarity-logo.png` — supplied company logo
- `assets/asarity-capability-profile-2026.pdf` — supplied capability profile
- `assets/asarity-photo-*.jpg` — nine original photographs supplied for the website

## Preview locally
Open `index.html` in a browser. The quotation form prepares an email to `asaritysales@gmail.com`; it does not submit information to a server.

## Publish using GitHub Pages (free)
1. Create a GitHub repository, for example `asarity-website`.
2. Upload the contents of this folder (not the folder wrapper) so `index.html`, `styles.css`, `script.js`, `README.md` and `assets/` are in the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. Wait for GitHub Pages to publish the website; the public URL will appear on that page.

## Before launch
Confirm the preferred contact details and all product availability/specifications. The enquiry form opens the visitor's email application; it does not store form data.
